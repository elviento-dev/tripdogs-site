  📚  СОДЕРЖАНИЕ
═══════════════════════════════════════════════════════

  1.  🏠  Статья на главную страницу
  2.  🎮  Статья по тегу (например, Games)
  3.  🏷️  Новый тег (например, Books)
  4.  🎬  Добавляем в списки (аниме, фильмы, музыка)
  5.  ⚠️  Главные правила файлов
  6.  🎨  Шпаргалка по Markdown
  7.  🛠️  Чек-лист, если build.bat ругается


═══════════════════════════════════════════════════════
  🧭  СНАЧАЛА — ГЛАВНОЕ ПРАВИЛО
═══════════════════════════════════════════════════════

  Вы работаете ТОЛЬКО с папкой  content.
  Остальные файлы (index.html, articles/, lists/, tags/)
  создаются сами. Их трогать не надо. 🙅

     TripDogs/
     ├── content/        ← ТУТ ВЫ РАБОТАЕТЕ ✏️
     │   ├── articles/   ← статьи
     │   ├── lists/      ← списки (аниме, фильмы, музыка)
     │   └── tags/       ← теги
     ├── build.bat       ← двойной клик = обновить сайт 🔄
     └── ...


═══════════════════════════════════════════════════════
  🏠  1. СТАТЬЯ НА ГЛАВНУЮ СТРАНИЦУ
═══════════════════════════════════════════════════════

  Шаг 1. Откройте папку  content\articles
  Шаг 2. Создайте новый файл, например  my-first-post.md
         (Правой кнопкой мыши → Создать → Текстовый документ,
          потом переименуйте и поменяйте расширение на .md)
  Шаг 3. Откройте его в Блокноте и вставьте шапку:

     ---
     title: "Моя первая статья"
     date: "2026-10-10"
     category: "Personal"
     tags:
     ---

     # Моя первая статья

     Тут пишем текст статьи.

  Шаг 4. Сохраните файл (Ctrl + S).
  Шаг 5. Дважды щёлкните  build.bat  и ждите надпись «Done».

  🎉  Статья появится на главной странице!

  💡  Что значат строки шапки:
      title     — заголовок статьи
      date      — дата в формате ГГГГ-ММ-ДД (2026-10-10)
      category  — раздел (можно написать что угодно)
      tags:     — теги. Пусто = статья на главной.


═══════════════════════════════════════════════════════
  🎮  2. СТАТЬЯ ПО ТЕГУ (НЕ НА ГЛАВНОЙ)
═══════════════════════════════════════════════════════

  Если у статьи ЕСТЬ тег, она НЕ попадает на главную.
  Она появится только на странице этого тега.

  Пример: статья про игру, файл  content\articles\my-game.md

     ---
     title: "Моя любимая игра"
     date: "2026-10-12"
     category: "Games"
     tags:
       - Games
     ---

     # Моя любимая игра

     Текст про игру...

  Обратите внимание: тег с новой строкой и дефисом.
  Отступ — два пробела перед дефисом. Не используйте Tab!

  🎮  Результат:  Tags → Games → «Моя любимая игра»
      На главной её НЕТ. Так и должно быть. 👍


═══════════════════════════════════════════════════════
  🏷️  3. СОЗДАЁМ НОВЫЙ ТЕГ (например, Books)
═══════════════════════════════════════════════════════

  Шаг 1. Откройте папку  content\tags
  Шаг 2. Создайте файл  books.md  и напишите:

     ---
     title: "Books"
     ---

  Шаг 3. Чтобы статья попала в этот тег, в её шапке пишем:

     tags:
       - Books

  Шаг 4. Запускаем  build.bat.

  🎉  Появятся страница  tags/books.html  и строчка «Books»
      на странице Tags.

  ⚠️  Имя файла тега пишем латиницей, без пробелов:
      books.md  ✅        Книги.md  ❌        my books.md  ❌


═══════════════════════════════════════════════════════
  🎬  4. СПИСКИ: АНИМЕ, ФИЛЬМЫ, МУЗЫКА
═══════════════════════════════════════════════════════

  Файлы списков:
     content\lists\anime.md   ← Anime / Cartoons
     content\lists\films.md   ← Movies
     content\lists\music.md   ← Music

  Откройте нужный файл и добавьте строчки, например:

     # Anime / Cartoons

     ## 2026

     - **Serial Experiments Lain** — 9/10
     - **Cowboy Bebop** — 10/10

  ✨  Каждая новая строчка начинается с  -  (дефис и пробел).
  ✨  Заголовок  ## 2026  делает раздел. Можно добавить
      ## 2025 и так далее.

  Сохраните, запустите  build.bat  — и список обновится! 🐕

  🗑️  Чтобы убрать заглушку «There's nothing here yet…»,
      просто удалите эту строку из файла.


═══════════════════════════════════════════════════════
  ⚠️  5. ГЛАВНЫЕ ПРАВИЛА ФАЙЛОВ
═══════════════════════════════════════════════════════

  🚫  Не ставьте  _  в начале имени файла.
      Файлы вида  _template.md  — это шаблон, сайт их
      ПРОПУСКАЕТ. Если назвать статью  _my-post.md,
      она не появится на сайте.

  🚫  Не используйте пробелы и кириллицу в имени файла.
      my-post.md   ✅      Моя статья.md   ❌

  🚫  Отступы в шапке — только пробелы, никаких Tab.

  ✅  Дата только в формате  2026-10-10  (год-месяц-день).

  ✅  Файлы сохраняйте в кодировке UTF-8.
      (В Блокноте: Файл → Сохранить как → Кодировка: UTF-8.)

  ✅  Шапка всегда начинается и заканчивается строкой  ---

  🐾  Двойное расширение  .md.md  ❌
      Windows часто сама добавляет .txt, и выходит  my-post.md.txt
      или  my-post.md.md. Чтобы этого не было:

      1. Откройте Проводник (📁).
      2. Вкладка «Вид» → включите галочку
         «Расширения имён файлов».
      3. Теперь видно настоящее имя. Переименуйте в  my-post.md.

      Для проверки: имя должно кончаться ровно на  .md


═══════════════════════════════════════════════════════
  🎨  6. ШПАРГАЛКА ПО MARKDOWN (ОФОРМЛЕНИЕ ТЕКСТА)
═══════════════════════════════════════════════════════

  Markdown — это простые значки вокруг текста.

  ┌──────────────────┬─────────────────────────────┐
  │ Что хотим        │ Что пишем                    │
  ├──────────────────┼─────────────────────────────┤
  │ Большой заголовок│ # Заголовок                  │
  │ Средний          │ ## Заголовок                 │
  │ Маленький        │ ### Заголовок                │
  │ Жирный текст     │ **жирный**                   │
  │ Курсив           │ *курсив*                     │
  │ Код (кусочек)    │ `код`                        │
  │ Список           │ - пункт                      │
  │ Цитата           │ > текст цитаты               │
  │ Линия            │ ---  (отдельной строкой)     │
  │ Ссылка           │ [текст](https://www.deepl.com) │
  └──────────────────┴─────────────────────────────┘

  🐕  Пример цитаты:

     > Собака — лучший друг человека.

  🔗  Пример ссылки:

     Мой любимый переводчик — [DeepL](https://www.deepl.com)

  🖼️  КАРТИНКИ
      1. Создайте папку  images  прямо в папке TripDogs
         (рядом с content, articles и т.д.).
      2. Положите туда картинку, например  dog.png.
      3. В статье пишем:

         ![Смешной песик](../images/dog.png)

      📌  Путь начинается с  ../  — это значит «выйти на
          уровень выше», потому что статьи лежат в папке articles.

      📌  Картинки в формате  .png  или  .jpg. Старайтесь
          не делать их очень большими.


═══════════════════════════════════════════════════════
  🛠️  7. ЧЕК-ЛИСТ: build.bat ВЫДАЁТ ОШИБКУ?
═══════════════════════════════════════════════════════

  Пройдите по пунктам сверху вниз. 🐾

   ☐  Сохранён ли файл? (Ctrl + S — да!)
   ☐  Имя файла заканчивается на  .md  (не .md.txt)?
   ☐  Нет ли пробелов и кириллицы в имени файла?
   ☐  Начинается ли файл с  ---  и есть ли закрывающее  ---?
   ☐  Есть ли кавычки у заголовка:  title: "Текст"  ?
   ☐  Дата в формате  2026-10-10  ?
   ☐  Отступы в шапке — пробелы, а не Tab?
   ☐  Тег из шапки совпадает с файлом в content\tags?
          (например, в шапке  Games  → нужен  games.md)
   ☐  Не начинается ли имя файла с  _  ?

  📋  Что написано в окне build.bat?
      Там будет подсказка вида:

         BUILD ERROR:
         Could not parse content/articles/my-post.md
         Reason: missing required field: date
         Line: 1

      Это значит: открываем  my-post.md, смотрим
      на указанную строку и исправляем причину.

  🔁  После исправления снова запустите  build.bat.

  🆘  Если ничего не помогает — сделайте скриншот окна
      build.bat и пришлите его. Разберёмся вместе! 🐶
